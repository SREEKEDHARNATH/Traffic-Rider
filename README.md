# Traffic-Rider

## You ride car through traffic 

This is a c++ sdl2 build of a traffic rider it just go indefinetly and you have to dodge it.

The issue that i got was for the bush not falling properly and the physics too.

All assets are hand drawn by me.

But traffics are falling bushes.

In here api.cpp handle images, listeners they are listeners for key events and mouse events and physics handle creation of bodies and world creation too and window handles the rest game time is infinite as long you dont touch bush or go too high or down good luck.

Running it is simple just download appimage use chmod +x the app image and ./appimage to run.

### Controls

Arrow keys
